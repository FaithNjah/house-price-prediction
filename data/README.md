# Data

`housing.csv`: 545 houses from the [Housing Prices Dataset](https://www.kaggle.com/datasets/yasserh/housing-prices-dataset) on Kaggle.

| Column | Description |
|---|---|
| price | Sale price (target) |
| area | Plot area in square feet |
| bedrooms, bathrooms, stories, parking | Counts |
| mainroad | Connected to a main road (yes/no) |
| guestroom, basement | Has a guest room / basement (yes/no) |
| hotwaterheating, airconditioning | Has hot water heating / air conditioning (yes/no) |
| prefarea | Located in a preferred area (yes/no) |
| furnishingstatus | furnished / semi-furnished / unfurnished |

The file is small (about 30 KB), so it's included here to let the project run straight after cloning.
